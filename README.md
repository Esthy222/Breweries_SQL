# Breweries Sales & Profit Analysis (SQL)

## Project Overview
This project performs an exploratory data analysis on the *Breweries* dataset using SQL. It evaluates key business performance indicators such as overall revenue and profit, yearly sales trends, product brand performance, and regional profitability across operating countries.

## Tools & Technologies Used
* *Database / Dialect:* PostgreSQL / MySQL
* *Key SQL Concepts:* Data Aggregation (SUM), Number Formatting (TO_CHAR), Grouping (GROUP BY), Sorting (ORDER BY), Aliasing (AS).

## Business Questions Answered
1. *Overall Performance:* What is the total revenue and profit generated across all sales?
2. *Yearly Analysis:* How do revenue and profit trends compare year-over-year?
3. *Brand Performance:* Which brewery brands drive the highest sales volume and revenue?
4. *Geographic Distribution:* Which countries generate the highest profit margins?

## File Structure
* Breweries_analysis.sql: Contains all structured SQL queries used for the analysis.
